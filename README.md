# light-wails-timer

Минималистичный таймер обратного отсчёта для рабочего стола: живёт в системном трее, показывает состояние цветом иконки и напоминает о завершении интервала системным уведомлением.

- Интервалы: 15, 30 и 60 минут; активен всегда только один.
- Иконка трея: серый кружок — таймер неактивен, зелёный — идёт отсчёт, жёлтый — на паузе.
- Подсказка при наведении на иконку: `light-wails-timer` (на XFCE панель кеширует текст подсказки, поэтому живой остаток там не обновляется — он виден в окне и в статусе меню).
- Меню трея: при активном таймере — «Пауза» и «Остановить», на паузе — «Продолжить» и «Остановить», при неактивном — «Запустить на 15/30/60 минут», плюс «Показать окно», автозапуск и «Выход».
- Компактное окно со стандартным заголовком: кольцо прогресса, остаток `MM:SS`, три кнопки пресетов, «Пауза»/«Продолжить» и «Стоп». Крестик скрывает окно в трей и не завершает приложение. На XFCE оно открывается пунктом «Показать окно» в меню трея (плагин Status Tray показывает меню по щелчку и не передаёт приложению щелчок напрямую).
- Отсчёт по абсолютному дедлайну: переживает сон системы и перезапуск приложения. Пауза замораживает остаток и тоже сохраняется между запусками.
- Беззвучное системное уведомление по завершении.
- Переключатель автозапуска при входе в сессию.

Сделано на [Wails v3](https://v3.wails.io) (Go + TypeScript), приёмка проведена на XFCE/X11.

## Требования

- Go 1.26 или новее.
- Wails CLI v3.0.0: `go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0`
- Node.js 20+ и npm (сборка фронтенда).
- Linux (проверено на XFCE 4.18, X11):
  - `libwebkit2gtk-4.1-dev`, `libsoup-3.0-dev`, `gtk+-3.0` для сборки;
  - плагин **Status Notifier** на панели XFCE (иначе иконки не будет);
  - демон уведомлений `xfce4-notifyd` (обычно уже установлен);
  - подсказка в трее зависит от панели: если она не показывается, остаток всегда виден в окне.

## Сборка и запуск

```bash
npm install --prefix frontend
wails3 build -tags gtk3
./bin/light-wails-timer            # иконка в трее, окно скрыто
./bin/light-wails-timer --show     # сразу открыть окно
```

Тег `gtk3` обязателен: Wails v3 по умолчанию собирается под GTK4/WebKitGTK 6.0, а приложение рассчитано на GTK3/WebKitGTK 4.1.

Флаг `--show` пригодится и как запасной путь, если панель не показывает иконку трея.

### Если окружение нестандартное

В этом репозитории Wails CLI может лежать локально, а кеши Go и npm — внутри проекта:

```bash
export PATH="$PWD/.tools:$PATH"
export GOCACHE="$PWD/.tools/gocache"
export GOMODCACHE="$PWD/.tools/gomodcache"
export GOSUMDB=off
export npm_config_cache="$PWD/.tools/npm-cache"
```

## Разработка

```bash
export PATH="$PWD/.tools:$PATH"
wails3 dev -config ./build/config.yml -port 9245
```

Задача сборки в `Taskfile.yml` уже передаёт тег `gtk3`, так что `wails3 task build` и режим разработки используют ту же конфигурацию.

Проверки:

```bash
go vet -tags gtk3 ./...
go test -tags gtk3 ./...
openspec validate --strict
```

## Где хранятся данные

- Состояние активного таймера: `$XDG_STATE_HOME/light-wails-timer/state.json` (по умолчанию `~/.local/state/light-wails-timer/state.json`), права `0600`, версия схемы в файле.
- Автозапуск: `~/.config/autostart/light-wails-timer.desktop` (создаётся при включении переключателя).
- Уведомления и трей: штатные механизмы платформы (D-Bus `org.freedesktop.Notifications` и StatusNotifierItem на Linux).

## Кроссплатформенность

Трей, уведомления, автозапуск и «один экземпляр» реализованы средствами Wails v3, поэтому Linux-специфичного кода в приложении нет. Сборка под Windows и macOS:

```bash
wails3 build -os windows
wails3 build -os darwin
```

Приёмка в этом изменении проведена только на Linux/XFCE; поведение на Windows и macOS не проверялось.

## Известные ограничения

- Несколько таймеров, помидорные циклы, звуковой сигнал и история — вне текущей версии.
- На XFCE текст подсказки иконки кешируется панелью, поэтому она не показывает обратный отсчёт; остаток времени смотрите в окне или в статусной строке меню.
- На XFCE первичный щелчок по иконке открывает меню трея, а не окно: плагин Status Tray не передаёт приложению `Activate`. Окно открывается пунктом «Показать окно», повторным запуском приложения или флагом `--show`. На панелях, которые передают щелчок, окно открывается и скрывается кликом.
- Кольцо прогресса рисуется только в окне; иконка трея статична (серый/зелёный/жёлтый кружок).
- После сна системы уведомление может появиться с задержкой до нескольких секунд: завершение обрабатывается первым тиком после пробуждения.
- На Wayland позиционирование окна у иконки может свестись к центру экрана.
- Если демон уведомлений недоступен, таймер всё равно сбрасывается, а в окне показывается предупреждение.
