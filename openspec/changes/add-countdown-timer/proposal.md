# Proposal

## Why

Нужен минималистичный трекер времени: один обратный отсчёт на 15, 30 или 60 минут, видимое состояние в трее и уведомление по завершении. Сейчас под рукой нет инструмента, который жил бы в трее XFCE и не требовал держать открытым окно. Заодно это первое практическое применение только что вышедшего Wails v3: проверить стек на реальном приложении.

## What Changes

- Новое десктоп-приложение **light-wails-timer** на Wails v3: один бинарник, трей-иконка и компактное окно.
- Три пресета интервала — 15, 30 и 60 минут; новый запуск заменяет текущий таймер, одновременно активен только один.
- Иконка трея: серый кружок — таймер неактивен, зелёный — активен; в окне остаток `MM:SS` и кольцо прогресса.
- Уведомление о завершении интервала (беззвучное), затем автоматический сброс в неактивное состояние.
- Отсчёт по абсолютному дедлайну: таймер честно истекает во время сна системы и переживает перезапуск приложения.
- Переключатель автозапуска при входе в сессию, отражающий фактическую регистрацию в системе.
- Один экземпляр приложения: повторный запуск показывает окно уже работающего процесса.

Вне рамок изменения: несколько параллельных таймеров, помидорные циклы, звуковые сигналы, история и статистика, локализация кроме русской, упаковка в AppImage/deb, приёмка на Windows и macOS.

## Capabilities

### New Capabilities

- `timer`: жизненный цикл одного обратного отсчёта — пресеты 15/30/60, запуск и замена, остановка, отсчёт по стенным часам, завершение, сохранение и восстановление состояния.
- `tray-ui`: постоянный доступ из системного трея — цвет иконки по состоянию, подсказка с остатком, меню, компактное окно с пресетами, остатком и кольцом прогресса.
- `desktop-integration`: связь с рабочим столом — системные уведомления о завершении, деградация без службы уведомлений, автозапуск при входе и кроссплатформенные механизмы.

### Modified Capabilities

Нет: проект создаётся с нуля, существующих спецификаций нет.

## Impact

- **Код**: новый Go-модуль `light-wails-timer`, пакеты `internal/timer`, `internal/store`, точка входа `main.go`, фронтенд `frontend/` (vanilla TypeScript + Vite).
- **Зависимости**: Wails v3.0.0 (`github.com/wailsapp/wails/v3@v3.0.0`), Node.js для сборки фронтенда, Go ≥ 1.26 (требование `go.mod` Wails).
- **Системные зависимости Linux**: `libwebkit2gtk-4.1-dev`, `libsoup-3.0-dev`, GTK3 (сборка с тегом `gtk3`, так как GTK4 в окружении нет); для уведомлений — служба `org.freedesktop.Notifications` (в XFCE это `xfce4-notifyd`, установлен), для трея — плагин Status Notifier в `xfce4-panel`.
- **Файлы пользователя**: состояние таймера в `$XDG_STATE_HOME/light-wails-timer/state.json` (по умолчанию `~/.local/state/light-wails-timer/state.json`), запись автозапуска `~/.config/autostart/light-wails-timer.desktop`.
- **Риски**: Wails v3.0.0 — свежий релиз, API может меняться; версия фиксируется в задачах и README.
